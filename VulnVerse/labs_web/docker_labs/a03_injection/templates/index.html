SQL Injection Vulnerability Lab

This lab demonstrates three different SQL injection vulnerabilities:

  1. Login Form: The login form is vulnerable to authentication bypass. Try Login Form
  2. Product Search: The search functionality is vulnerable to data extraction. Try Product Search
  3. User Profile: The user profile page is vulnerable to data manipulation. Login to Try User Profile

Instructions:

1. Start by exploring the login form vulnerability. Can you bypass authentication?

2. After logging in, try the product search functionality to extract hidden data.

3. Finally, explore the user profile page to see if you can access or modify other users' data.
